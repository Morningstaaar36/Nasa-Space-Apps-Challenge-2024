# Sunclimate Chronicles (NASA Space Apps Challenge 2024)

A web app for exploring greenhouse-gas data from the U.S. Greenhouse Gas Center (MiCASA carbon flux and CH₄) on a map, with comparison and statistics views. React + TypeScript (Vite) frontend, Django REST backend.

## Team

Fork of the team repository [heisamit3/Nasa-Space-Apps-Challenge-2024](https://github.com/heisamit3/Nasa-Space-Apps-Challenge-2024). Built by Amit Saha (original author), sadiasayed68, usaben and Morningstaaar36.

## My role

I built the Django backend (`backend/`): login and signup with models and serializers, the carbon-data map endpoints, and the MiCASA comparison and statistics views, and integrated the backend with the frontend.

## Running

```bash
cd backend && python manage.py runserver
cd frontend && npm install && npm run dev
```
